# Solitario Spider

Aplicativo desktop de Solitario Spider desenvolvido em Python.

## Objetivo

Criar um jogo de cartas com interface grafica, regras classicas do
Spider de quatro naipes e recursos de personalizacao visual.

## Tecnologias

- Python
- PySide6
- pytest

## Funcionalidades planejadas

- Baralho e regras do Spider de quatro naipes.
- Distribuicao e movimentacao de cartas.
- Interface grafica para computador.
- Temas, fundos, molduras, ilustracoes e versos personalizaveis.
- Salvamento local e estatisticas.
- Testes automatizados.

## Desenvolvimento

O projeto sera desenvolvido por etapas, com arquivos pequenos,
responsabilidades separadas e testes ao longo da implementacao.

## Estado atual

Fundacao do projeto em preparacao.
